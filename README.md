# Fakhama Touch — Salla Twilight Theme

ثيم مخصص لمتجر فخامة تت، مبني على Salla Twilight.

## قبل الرفع
1. أنشئ مستودع GitHub جديد باسم `fakhama-touch-theme`.
2. غيّر رابط `repository` داخل `twilight.json` إلى رابط مستودعك.
3. ارفع جميع الملفات إلى المستودع.
4. من Salla Partners Portal اختر Import Theme واربط المستودع.
5. شغّل المعاينة، ثم اختبر الجوال والمنتج والسلة والبحث والدفع قبل التفعيل.

## تطوير محلي
- Node.js 22+
- pnpm install
- pnpm run development
- salla theme preview
